# 循迹 · 健身打卡

一款简洁的 Android 本地健身记录应用，帮助你安排训练、完成每日打卡，并持续记录饮食与身体变化。无需注册账号，可离线使用。

## 主要功能

- **训练计划**：导入标准模板格式的 Word / PDF，或手动创建训练日，自定义动作、训练要求与顺序。
- **每日打卡**：选择当天的训练日，逐项勾选或一键完成，记录实际负重、组次和训练感受。
- **饮食记录**：分别记录早餐、午餐、晚餐和加餐，热量可手动填写。
- **身体趋势**：记录体重、体脂率和腰围，查看不同时间范围内的变化曲线。
- **本地管理**：查看存储占用，按日期范围清理历史记录；修改训练日模板不会影响已有的每日训练快照。

## 简单上手

1. 在「计划」下载标准模板，填写后导入 Word / PDF 并确认训练日，也可手动创建。
2. 在「今日」选择训练日，完成打卡，填写饮食、训练记录和身体指标。
3. 在「趋势」查看身体变化与训练统计。

支持 **Android 15 及以上版本**。所有记录保存在应用本地，不提供云同步；卸载应用或清除应用数据会丢失本地记录。PDF 文字提取不支持扫描件 OCR。
